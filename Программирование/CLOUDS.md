 Сервер - это обычный компьютер, на котором запущена программа. Кстати, это может быть и не один компьютер, а несколько связанных, тогда это будет распределённая система. Распределённая система состоит из нескольких компьютеров, каждый из которых выполняет определенные функции и обменивается информацией с другими компьютерами в сети. В распределённой системе каждый компьютер называется узлом, а все узлы работают вместе, чтобы предоставить необходимые ресурсы и услуги пользователям.
 
Continuous integration - набор практик для автоматизации постоянной интеграции новых изменений в основной репозиторий.

Continuous deployment - набор практик для автоматизации постоянного деплоя новый версий приложения

Облака - этоо просто такие же компьютеры, но которые находятся в чьем то датацентре. Я могу такие сервера арендовать на время, чтобы использовать их ресурсы. А их владельцы позаботятся об обслуживании и поддержке.

## Docker
Специальная программа, позволяющая быстро устанавливать и затем управлять всеми внешними зависимостями моих приложений.

Контейнер - маленькая и легковесная ОС вместе с только необходимыми программами, нужными для запуска того или иного приложения.

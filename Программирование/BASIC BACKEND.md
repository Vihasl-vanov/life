## Сервер
 это обычный компьютер, на котором запущена программа. Кстати, это может быть и не один компьютер, а несколько связанных, тогда это будет распределённая система. Распределённая система состоит из нескольких компьютеров, каждый из которых выполняет определенные функции и обменивается информацией с другими компьютерами в сети. В распределённой системе каждый компьютер называется узлом, а все узлы работают вместе, чтобы предоставить необходимые ресурсы и услуги пользователям.
## DNS (Domain Name System)
Это система, которая переводит доменные имена в IP-адреса.  DNS — это распределённая база данных, которая хранит соответствия между доменным именем и IP-адресом.![[Снимок экрана 2025-09-01 в 11.15.36.png]]

## IP-адрес
 это числовой идентификатор устройства в сети. У любого компьютера, который подключен к сети, есть IP адрес. IPv4 адреса состоят из 4 чисел, разделенными точками. Например: 127.0.0.1 - это адрес вашего локального компьютера, более широко известный по своему имени — localhost.

Чтобы несколько программ могли одновременно работать на одном компьютере, все программы запускаются на разных портах. Одно приложение может работать только на одном порте.

Итак, DNS предоставляет клиенту IP-адреc, например, 12.35.11.52. Затем нужно по порту найти нужную программу, запущенную на сервере. Так, например, нужная программа будет работать по адресу: 12.35.11.52:8080 — на этот адрес клиент отправляет HTTP-запрос.

#### Общая схема работы (от пользователя к сайту)

1. **Запрос DNS:** Браузер получает от DNS IP-адрес сервера, на котором находится сайт.
    
2. **Установление соединения (TCP):** Браузер использует IP и порт для установки надежного TCP-соединения с сервером.
    
3. **Отправка HTTP-запроса:** После установления соединения браузер отправляет HTTP-запрос (например, "покажи главную страницу") на конкретный порт веб-сервера (например, 80 для HTTP или 443 для HTTPS).
    
4. **Обработка запроса:** Программа (веб-сервер, например, Nginx или Apache), "слушающая" на том порту, получает запрос, обрабатывает его и формирует ответ.
    
5. **Получение ответа:** Браузер получает HTTP-ответ (HTML, CSS, JS) и отображает страницу.

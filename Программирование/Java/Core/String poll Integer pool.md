**String pool** и **Integer pool** (и аналогичные пулы для других обёрток, например, `Long`, `Short`) нужны для оптимизации памяти и производительности:

1. **String pool** (хранит строки в heap) – позволяет избежать создания дубликатов строк, переиспользуя существующие. Работает благодаря иммутабельности строк.
    
2. **Integer pool** (кеширует числа от -128 до 127 по умолчанию) – уменьшает нагрузку на память, переиспользуя часто используемые объекты-обёртки.
    

Оба пула работают по принципу **interning** (интернирования) – переиспользование объектов вместо создания новых.

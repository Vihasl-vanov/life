 JVM (Java Virtual Machine) - Это виртуальная машина, которая исполняет байт код(.class  файлы). Ее главная задача - это обеспечение кроссплатформенности(Write once run anywhere). Jvm читает байткод -> интерпретирует или компилирует в машинный код(Jit-компиляции). Управляет памятью с помощью garbage collection.

JRE(Java Runtime Environment) - среда для запуска java программ. Она включает в себя JVM + различные библиотеки. Нет инструментов разработки. Только для тех кто хочет запустить приложение.

JDK(Java Development Kit) - Набор для разработки java-приложений. Включает в себя - JRE + **компилятор** (`javac`), отладчик, утилиты (`jconsole`, `jstack`).

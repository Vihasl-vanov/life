## Binary Tree
**Бинарное дерево** — это иерархическая структура данных, состоящая из узлов, где каждый узел имеет не более двух дочерних элементов, называемых левым и правым поддеревьями. Каждый узел в бинарном дереве связан с одним родительским узлом, за исключением корня, у которого нет родителя.

Давайте посмотрим на элементы деревьев:

**Корень (Root)**: Это верхний узел дерева, не имеющий родителя.

**Узел (Node)**: Каждый элемент дерева, который может содержать данные и ссылки на своих детей.

**Лист (Leaf)**: Узел, у которого нет детей.

**Поддерево (Subtree)**: Это часть дерева, включающая узел и все его потомки.

**Уровень (Level)**: Уровень дерева - это горизонтальный слой узлов, начиная от корня. Корень находится на уровне 0, его дети - на уровне 1 и так далее.
**Глубина (Depth)**: Глубина узла - это количество рёбер на пути от корня до данного узла.![[Снимок экрана 2025-12-10 в 16.55.12.png]]

Бинарные деревья могут быть структурированы по-разному, и для удобства понимания и манипуляции с данными деревья были условно разделены на категории в зависимости от структуры. Вот некоторые из тех, которые встречаются наиболее часто:

**Полное бинарное дерево (Full Binary Tree)**: Каждый узел имеет либо 0, либо 2 дочерних узла.Если в дереве только один узел, то такое дерево тоже считается полным бинарным.![[Снимок экрана 2025-12-10 в 16.56.27.png]]

**Сбалансированное бинарное дерево (Balanced Binary Tree или AVL Tree)**: Гарантирует, что глубина левого и правого поддеревьев отличается не более чем на 1.![[Снимок экрана 2025-12-10 в 16.58.43.png]]
Каждый узел AVL-дерева должен удовлетворять условию баланса, и в случае нарушения этого условия выполняются операции балансировки — вращения.

**Бинарное дерево поиска (Binary Search Tree)**: Удовлетворяет условию, что для каждого узла значения в его левом поддереве меньше его значения, а значения в правом поддереве больше. 

## Binary Search Tree
Ключевая особенность BST заключается в том, что для каждого узла значения в его левом под дереве меньше его значения, а значения в правом поддереве больше.

**Основные свойства BST:**

1. **Левое поддерево меньше правого**: Для каждого узла `N`, все значения в его левом поддереве `L` меньше значения `N`, и все значения в его правом поддереве `R` больше значения `N`. На картинке выше как раз видим это свойство: все значения в поддереве слева от 15 меньше 15, а все значения справа — больше.
    
2. **Уникальные значения**: Нет двух узлов с одинаковым ключом (значением).
    
3. **Рекурсивная структура**: Левое и правое поддеревья также являются двоичными деревьями поиска. Дерево не считается бинарным, если хотя бы одно его поддерево не является бинарным.

## Как обходить деревья

Обход бинарного дерева в порядке возрастания (**in-order**) начинается с корня дерева и последовательно посещает левое и правое поддеревья каждого узла, двигаясь вправо. Например, если у нас есть бинарное дерево с корневым узлом A, левым поддеревом B и правым поддеревом C, то обход в порядке возрастания будет выглядеть следующим образом: B, A, C .

```
public void inorder(TreeNode node){
    if(node == null)
        return;

    inorder(node.left);
    System.out.println(node.val);
    inorder(node.right);
}
```

Обход бинарного дерева в порядке убывания (**pre-order**) начинается с корня дерева и последовательно посещает левое и правое поддеревья каждого узла, двигаясь влево. Например, если у нас есть бинарное дерево с корневым узлом A, левым поддеревом B и правым поддеревом C, то обход в порядке убывания будет выглядеть следующим образом: A,B,C.
```
public void preorder(TreeNode node){
    if(node==null)
        return;

    System.out.println(node.val);
    preorder(node.left);
    preorder(node.right);
}
```
Обход бинарного дерева в порядке появления (**post-order**) начинается с корня дерева и последовательно посещает левое и правое поддеревья каждого узла, двигаясь влево и вправо. Например, если у нас есть бинарное дерево с корневым узлом A, левым поддеревом B и правым поддеревом C, то обход в порядке появления будет выглядеть следующим образом: B, C, A.

```
private void postorder(TreeNode node){
    if(node == null)
        return;

    postorder(node.left);
    postorder(node.right);
    System.out.println(node.val);
}
```

Эти три типа обходов являются различными способами обойти бинарное дерево и могут использоваться в зависимости от конкретной задачи или алгоритма. Например, обход в порядке возрастания может быть полезен, когда необходимо найти наименьшее или наибольшее значение в дереве, тогда как обход в порядке убывания может быть полезен, когда необходимо найти наименьшее или наибольшее значение в обратном порядке. Обход в порядке появления может быть полезен, когда необходимо найти значения в определенном порядке, например, в порядке возрастания или убывания.
## Recursion
Рекурсия - метод вызывает сам себя. Обязательно должно быть условие прерывания рекурсии. Всегда Time: O(n), Space: O(n). Если точно знаешь размер то константа.

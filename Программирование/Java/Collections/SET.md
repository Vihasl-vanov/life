
- Элементы уникальны. Если попытаться добавить элемент, который уже содержится в множестве, он просто перезапишется.
- У множества отсутствует индексация, т.е. элементы не упорядочены.
- Можно быстро проверить, содержится ли какой элемент в множестве.
- Размер множества динамичен.
- Популярные реализации — `HashSet`, `TreeSet`, `LinkedHashSet`.

`HashSet` основан на хэш-функции. По сути, такой же как `HashMap`, только без элементов.В качестве значения выступает объект заглушка (в коде называется `PRESENT`), для работоспособности `HashMap`.

У `HashSet` тоже могут возникать коллизии, поведение такое же, как и у `HashMap`.
Сложность в среднем — `O(1)`, в худшем — `O(N)`. Может стать `O(logn)`. Все как у `HashMap`.

TreeSet Операции поиска `get` в `TreeSet` нет, потому что `TreeSet` реализует интерфейс `SortedSet`, который не предоставляет такой операции, в отличии от `List` или `Map`, где элементы доступны по индексу.

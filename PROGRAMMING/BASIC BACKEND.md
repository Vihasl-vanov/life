
## DNS (Domain Name System)
Это система, которая переводит доменные имена в IP-адреса.  DNS — это распределённая база данных, которая хранит соответствия между доменным именем и IP-адресом.![[Снимок экрана 2025-09-01 в 11.15.36.png]]

## IP-адрес
 это числовой идентификатор устройства в сети. У любого компьютера, который подключен к сети, есть IP адрес. IPv4 адреса состоят из 4 чисел, разделенными точками. Например: 127.0.0.1 - это адрес вашего локального компьютера, более широко известный по своему имени — localhost.

Чтобы несколько программ могли одновременно работать на одном компьютере, все программы запускаются на разных портах. Одно приложение может работать только на одном порте.

Итак, DNS предоставляет клиенту IP-адреc, например, 12.35.11.52. Затем нужно по порту найти нужную программу, запущенную на сервере. Так, например, нужная программа будет работать по адресу: 12.35.11.52:8080 — на этот адрес клиент отправляет HTTP-запрос.

#### Общая схема работы (от пользователя к сайту)

1. **Запрос DNS:** Браузер получает от DNS IP-адрес сервера, на котором находится сайт.
    
2. **Установление соединения (TCP):** Браузер использует IP и порт для установки надежного TCP-соединения с сервером.
    
3. **Отправка HTTP-запроса:** После установления соединения браузер отправляет HTTP-запрос (например, "покажи главную страницу") на конкретный порт веб-сервера (например, 80 для HTTP или 443 для HTTPS).
    
4. **Обработка запроса:** Программа (веб-сервер, например, Nginx или Apache), "слушающая" на том порту, получает запрос, обрабатывает его и формирует ответ.
    
5. **Получение ответа:** Браузер получает HTTP-ответ (HTML, CSS, JS) и отображает страницу.


## Linux basic commands
#### **Доступ и безопасность**

🔐 **SSH (Secure Shell)**

- Обеспечивает безопасный удаленный доступ к Linux-хостам.
    
- Команда: `ssh имя_пользователя@ip_адрес`
    
- Далее следует аутентификация по паролю.
    

👤 **Создание пользователя с правами sudo**

- Добавление нового пользователя: `sudo adduser имя_пользователя`
    
- Предоставление прав sudo: `sudo usermod -aG sudo имя_пользователя` (добавляет пользователя в группу `sudo`).
    

🔑 **Изменение прав владения файлами**

- Смена владельца и группы: `chown пользователь:группа имя_файла`
    
- Смена только группы: `chgrp группа имя_файла`
    

---

#### **Управление файлами**

🔗 **Символические ссылки**

- Создание: `ln -s исходный_файл имя_ссылки`
    
- Удаление: `rm имя_ссылки` (оригинальный файл не затрагивается).
    

📁 **Базовые операции с файлами**

- Копирование: `cp источник назначение`
    
- Перемещение/переименование: `mv источник назначение`
    
- Удаление: `rm имя_файла`
    

🗑️ **Необратимое удаление**

- Полное затирание файла: `shred имя_файла` (файл становится невосстановимым).
    
- Рекурсивное удаление каталога: `rm -rf имя_каталога` (удаляет папку и всё её содержимое).
    

📝 **Создание файлов**

- Создание пустого файла: `touch test.txt`
    

---

#### **Содержимое файлов и поиск**

📖 **Просмотр содержимого файла**

- Команда `cat` выводит всё содержимое файла.
    
- Полезно для просмотра небольших файлов или объединения нескольких файлов.
    

🔍 **Поиск текста в файлах**

- Эффективный поиск выполняется командой `grep`.
    
- Отображает строки и их номера, содержащие указанный текст.
    

---

#### **Системные и сетевые утилиты**

🌐 **Проверка сетевого подключения**

- Команда `ping` проверяет доступность хоста в сети и измеряет время отклика.
    

📊 **Мониторинг ресурсов системы**

- Мониторинг в реальном времени: команды `top` или `htop`.
    
- Показывают статистику по использованию CPU, памяти и запущенным процессам.
    

🔄 **Управление пакетами**

- Установка, обновление и удаление программного обеспечения.
    
- В Debian/Ubuntu: `apt-get` (например, `sudo apt-get install имя_пакета`).
    
- В RHEL/CentOS: `yum` (например, `sudo yum install имя_пакета`).
